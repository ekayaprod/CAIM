CAIM Automation Portal

Deploy the zero-touch bookmarklet engines to your browser.

1

Map the Target Form

Used strictly to update or capture the underlying page structure to a JSON file. Drag to bookmarks bar and run on an empty CAIM page.

Field Mapper
2

Wipe Profile (Clear Engine)

A dedicated, single-purpose engine that strictly wipes out existing data. It detects active fields, sets statuses to DELETE, unchecks arrays, and empties text boxes. (Requires the schema JSON to be imported via the Fill Engine first).

Clear Profile Engine
3

Populate Profile (Fill Engine)

The targeted data applicator. Run this to apply your Location/Role CSV presets to the page. Unspecified columns in your CSV are ignored. To deliberately wipe a specific column while leaving the rest of the profile intact, set the CSV value to __CLEAR__.

Fill Profile Engine
